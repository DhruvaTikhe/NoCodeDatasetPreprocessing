# No-Code Dataset Preprocessing for Machine Learning

This project is under a Mentorship program at Persistent Systems, Pune

The project aims to create a no code interface for running complicated preprocessing steps on datasets, in order to make them Machine Learning ready.
The project will be maintained and updated regularly as new features are implemented, bugs are fixed and scope is widened.

## Steps to run (Python has to be installed)
1. Download the zip file of the project
2. Open a terminal in the folder and run "pip install -r requirements.txt"
3. Then run "streamlit run app.py"
4. Upload the dataset and use the drop down menus to navigate the UI for preprocessing steps
